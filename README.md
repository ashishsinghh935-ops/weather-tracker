# 🌤️ Weather & Air Quality Tracker

A lightweight, responsive web application that provides real-time weather conditions, Air Quality Index (AQI) values, and a 5-day forecast for selected cities. 

## ✨ Features
* **Dynamic Location Selection:** Cascading dropdown menus allow users to select a state and then choose from available cities.
* **Live Weather & AQI:** Fetches real-time temperature, humidity, wind speed, and US AQI.
* **5-Day Forecast:** Displays daily high and low temperatures along with predicted weather conditions for the upcoming week.
* **No API Keys Required:** Fully powered by the open-source Open-Meteo API.

## 🛠️ Built With
* **HTML5** - Structure and layout
* **CSS3** - Modern styling, flexbox, and horizontal scrolling UI
* **JavaScript (ES6)** - DOM manipulation, state-to-city logic, and asynchronous API fetching
* **Open-Meteo API** - Live geocoding, weather, and air quality data
