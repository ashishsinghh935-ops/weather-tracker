# 🌤️ Weather & Air Quality Tracker

A lightweight, beginner-friendly web application built to check real-time weather conditions and Air Quality Index (AQI) values for any city. 

## 🛠️ Built With
* **HTML5** - Structure and layout
* **CSS3** - Modern styling, flexbox, and gradients
* **JavaScript (ES6)** - DOM manipulation and dynamic data handling
* **Git & GitHub** - Version control and code hosting
